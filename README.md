# Car Rental Data Warehouse Project

## Project Overview

This repository contains an **end-to-end data engineering project** based on a car rental business scenario. The goal of the project is to transform operational transactional data into an analytical 

**data warehouse designed using a star schema**.

1. OLTP --> OLAP DB through an ETL pipeline 
Starting from a normalized source schema, the project simulates real-world data workflows by implementing a pipeline that stages, transforms, and loads data into a warehouse optimized for analytics and reporting.

2. Data transformations and modeling will be implemented using **dbt (data build tool)** to structure, test, and document the transformation layer.
